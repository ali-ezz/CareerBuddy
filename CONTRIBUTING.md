# Contributing to CareerBuddy

Thank you for your interest in improving CareerBuddy.

## How to Contribute

- Open an issue for bugs, enhancements, or new feature ideas.
- Fork the repository and create a descriptive branch.
- Submit a pull request with a clear summary and testing notes.

## Branch Naming

Use descriptive branch names such as:

- `feature/add-job-filter`
- `bugfix/fix-job-fetch`
- `docs/update-readme`

## Pull Request Expectations

Include the following in your PR description:

- What changed and why
- How to test the change
- Any relevant issue number
- Screenshots or examples if applicable

## Review Process

- Pull requests will be reviewed by maintainers.
- Expect constructive feedback and small iterative improvements.
- Keep commits focused and avoid unrelated changes.

## Issues

- For bug reports, include reproduction steps and expected behavior.
- For feature requests, describe the use case and proposed experience.
