# Security Policy

If you discover a security vulnerability in CareerBuddy, please report it responsibly.

## Reporting

- Email: `security@careerbuddy.example.com`
- Alternatively, open an issue and mark it as confidential if your provider supports it.

## What to include

- Steps to reproduce the issue
- Expected and actual behavior
- Any relevant data or environment details

## Response

We aim to acknowledge reports within 48 hours and follow up with remediation plans.

## Disclosure

Please do not publicly disclose security issues before they are resolved.
